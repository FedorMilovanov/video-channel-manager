# Operations

Operational runbooks and safety-first recovery procedures live in this directory.

For YouTube comment work, use:

- `youtube-comment-refresh.md` for normal dry-run, update, create-only, and recovery workflows;
- `youtube-comment-recovery-checklist.md` for the closure evidence checklist;
- `youtube-comment-recovery-command.ps1` as the fail-closed Windows launcher template;
- `youtube-comment-recovery-design.md` for the architecture and incident-derived safety rules.
