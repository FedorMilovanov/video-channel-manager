# Quick operational start

1. Read `../../AGENTS.md`.
2. Read [`current-state.md`](current-state.md).
3. Confirm exact source and target IDs.
4. Confirm inventory coverage for the intended surface.
5. Use an immutable manifest with SHA-256.
6. Validate every operational ZIP with `scripts/verify_operational_bundle.py`.
7. Use a durable ledger and provider reread postconditions.
8. Update the run report, current state, and memory changelog after execution.
