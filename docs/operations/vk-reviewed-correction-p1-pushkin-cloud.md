## Основание correction-wave

Проверка по академическому тексту и комментарию, дневнику и письмам Пушкина, музейной биографической хронологии и атрибутированному литературоведческому исследованию выявила пять точных мест для исправления.

Разрешённые изменения:

1. убрать неподтверждённые абсолютные оценки и утверждение, будто двенадцать строк документируют «целую жизнь» и конкретный психологический перелом;
2. сохранить психологическое прочтение как интерпретацию, но не выдавать тучу за установленный автопортрет Пушкина;
3. исправить возраст поэта, число детей, дату первой публикации и хронологию камер-юнкерства и попытки отставки;
4. различить дуэль 27 января 1837 года и смерть Пушкина 29 января, не объявляя стихотворение доказанным пророчеством;
5. убрать неподтверждённые цитаты Белинского и Набокова, атрибутировать политическое прочтение Н. В. Измайлову как позднюю гипотезу и добавить документированное письмо Пушкина о правке предпоследней строки.

## Dry-run

Перед построением плана helper независимо проверяет завершённый apply-ZIP Блока и извлекает из него фактический финальный VK snapshot.

```powershell
pwsh -File .\scripts\Invoke-VkReviewedCorrectionPushkinCloudWave.ps1
```

Флаг `-Execute` отсутствует и не поддерживается. Команда выполняет только read-only preflight.

Ожидается:

```text
ready: 1
already applied: 0
conflicts: 0
remote writes: 0
```

Результат:

```text
data\handoffs\vk-reviewed-correction-p1-pushkin-cloud-dry-run-YYYYMMDD-HHMMSS.zip
```

Apply запрещён до независимой проверки ZIP, точного плана, after-state, источников, guard-хэша и отсутствия скрытых изменений.
