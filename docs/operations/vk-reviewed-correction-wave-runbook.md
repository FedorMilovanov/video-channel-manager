# VK reviewed correction wave — операционный регламент

Канал: **The Legendary Poet**  
Сообщество: `235216998`

## Назначение

Correction wave применяется только после source-backed редакционного решения. Она не является продолжением технической очистки и намеренно может менять содержательный текст, но только через заранее утверждённые точные замены.

## Первая P1-волна

Decision set:

```text
p1-esenin-confession-20260727
```

Точные VK ID:

```text
-235216998_456239046
-235216998_456239047
-235216998_456239050
```

Исправляются только два фрагмента в трёх описаниях «Исповедь самоубийцы»:

1. `1912 г.` заменяется на `1913–1915 гг. (предположительная датировка академического издания)`;
2. недоказуемое утверждение о том, что Есенин «умер в неверии», заменяется на осторожную формулировку, которая сохраняет христианскую позицию канала, но не выносит окончательный суд о личной вере исторического лица.

## Источники

Академическая датировка и атрибуция опираются на:

- Фундаментальную электронную библиотеку, текст «Исповеди самоубийцы» в полном собрании сочинений Есенина, том 4;
- академический комментарий к тому 4: недатированный автограф, предположительная датировка `1913–1915`, рука Есенина.

URL источников записаны непосредственно в reviewed decisions JSON и копируются в каждый correction handoff.

## Жёсткие ограничения

Волна блокируется, если:

- review-ZIP не совпадает по полному SHA-256;
- любой внутренний файл review-ZIP не совпадает с manifest;
- source plan SHA-256 отличается;
- изменилось название любого из трёх роликов;
- изменилось текущее описание любого из трёх роликов;
- старый фрагмент встречается не ровно один раз;
- отсутствует источник;
- в плане не ровно три операции;
- план пытается менять названия, альбомы, memberships, placements или состав видеотеки;
- live preflight возвращает конфликт.

## Dry-run

```powershell
pwsh -File .\scripts\Invoke-VkReviewedCorrectionWave.ps1
```

Helper автоматически выбирает:

- последний verified `vk-description-wave-apply-*.zip`;
- последний `vk-deferred-editorial-review-*.zip`;
- встроенный reviewed decisions JSON.

Он создаёт один файл:

```text
data\handoffs\vk-reviewed-correction-p1-dry-run-YYYYMMDD-HHMMSS.zip
```

Dry-run вызывает только чтение live VK inventory. `video.edit`, `video.editAlbum` и другие mutation methods не вызываются.

## После внешней проверки

Execute helper создаётся или включается только после независимой проверки dry-run ZIP. Он обязан:

1. загрузить точный подписанный plan из проверенного ZIP;
2. повторить live preflight;
3. проверить community, ready count, plan SHA-256, video coverage и memberships SHA-256;
4. выполнить не более трёх description-only операций;
5. проверить каждое описание после записи;
6. сделать final snapshot;
7. доказать отсутствие изменений названий, альбомов, memberships и состава видеотеки;
8. создать один apply-ZIP.

## Запрещено

- строить и тут же исполнять новый correction plan;
- применять correction без source evidence;
- исправлять весь research unit по приблизительному совпадению;
- менять poem text, ссылки, хэштеги или footer без отдельного reviewed decision;
- запускать writer параллельно с ручным редактированием VK Studio.
