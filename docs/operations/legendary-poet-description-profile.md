## Правила YouTube video descriptions

1. Payload генерируется как plain text.
2. Не использовать `**...**`, `*...*`, `_..._`, `__...__` как способ получить bold/italic в video description.
3. Rich-text оформление video description при необходимости применяется средствами интерфейса YouTube Studio.
4. Первый абзац точно описывает произведение, автора, исторический материал, музыкальную адаптацию или визуальный эксперимент.
5. Нельзя выдумывать даты, обстоятельства создания, цитаты, архивные факты, посвящения или авторские намерения.
6. URL остаются обычным видимым текстом; Markdown-links запрещены.
7. Плейлисты добавляются только по релевантности и точному известному URL.
8. Ссылки проекта «Господь Бог — Сила Моя» запрещены.
9. Кабинетные ссылки запрещены.
10. Publishable copy не содержит незаполненных template placeholders.

Точный transport/formatting contract: [`../youtube-description-rendering-standard.md`](../youtube-description-rendering-standard.md).

## Правила ChatGPT/operator handoff

Если пользователь просит только готовое YouTube-описание или закреплённый комментарий, итоговый copy/paste текст должен быть выдан в одном fenced code block с пометкой `text` и без объяснений до/после.

Этот code fence — только транспорт чата и не входит в YouTube payload.

## Правила YouTube comments

Комментарии и закреплённые комментарии — отдельная поверхность. Для них допустимы поддерживаемые YouTube comment tags `*bold*`, `_italic_`, `-strikethrough-`; эти правила нельзя переносить на video descriptions.

## Правила VK Видео и VK Клипов

VK-описания являются простым текстом. Перед публикацией нужно снять неподдерживаемые платформой маркеры, сохранив слова, пунктуацию, абзацы, ссылки, хештеги и проверенные таймкоды.

Для обычного VK Видео можно использовать сайт, Telegram, канонический VK и RUTUBE. Публичную ссылку на VK Clips добавлять только там, где она помогает зрителю перейти к коротким роликам.
