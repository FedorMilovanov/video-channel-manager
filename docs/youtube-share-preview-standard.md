# YouTube SHARE-превью и первый абзац

Канал: **The Legendary Poet**  
Статус: **обязательное уточнение** к `youtube-description-rendering-standard.md`.

## Подтверждённое поведение

На странице просмотра YouTube отображает разметку `*жирного*` и `_курсива_` в описании. Однако карточка, открываемая кнопкой **Поделиться / SHARE**, показывает фрагмент первого абзаца обычным текстом и не передаёт визуальное выделение.

Это проверено владельцем на описании ролика «Веня Д’ркин — Anno Domini»: выделения внутри первого абзаца видны в полном описании, но не видны в SHARE-превью.

## Обязательное правило

Первый смысловой абзац описания:

- не содержит парных маркеров `*...*` и `_..._`;
- сохраняет всю формулировку и пунктуацию обычным текстом;
- может начинаться с одного уместного эмодзи;
- не обязан содержать эмодзи;
- не содержит ссылочный или технический блок.

Разметка во втором и последующих абзацах разрешена и сохраняется.

### Было

```text
Веня Д’ркин — поэт, чья сила — _беспощадная ясность._ Его песни звучат как свет.

*Anno Domini* по-латыни означает «в лето Господне».
```

### Должно быть

```text
Веня Д’ркин — поэт, чья сила — беспощадная ясность. Его песни звучат как свет.

*Anno Domini* по-латыни означает «в лето Господне».
```

Изменяются только маркеры первого абзаца. Слова, знаки препинания и последующие выделения не переписываются.

## Автоматическая проверка

Код ошибки:

```text
share_preview_emphasis
```

Это не означает, что полное описание сломано. Ошибка означает несовместимость первого абзаца с визуальным представлением SHARE-превью канала.

Валидатор не должен принимать за разметку:

- подчёркивания внутри URL;
- YouTube ID с `_`;
- буквальное название `К ***`;
- непарные символы, которые уже отдельно считаются ошибкой обёртки.

## Безопасный автофикс

`scripts/autofix_youtube_copy.py` автоматически:

1. снимает парные `*` и `_` только в первом абзаце;
2. сохраняет разметку во всех следующих абзацах;
3. переносит внутрь выделения только безопасную завершающую пунктуацию;
4. удаляет лишнюю точку после уже имеющихся `?`, `!` или `…`;
5. переносит двоеточие внутрь подписей `VK`, `Telegram`, `RUTUBE` и плейлистов;
6. оставляет объяснительное двоеточие снаружи для ручной синтаксической оценки;
7. сводит несколько пустых строк к одной;
8. не меняет эмодзи, факты, названия, ссылки, длинные абзацы и литературные трактовки.

Скрипт формирует локальный JSON-план и Markdown-diff. Он не изменяет YouTube и не перезаписывает исходный `AuditPackage`.

## Запуск

```powershell
python .\scripts\autofix_youtube_copy.py `
  .\data\exports\youtube-legendary-poet-UC-78ys2S3cQ3lpqgXfo-SvQ-20260724-202430.json
```

По умолчанию появятся:

```text
data\reports\youtube-legendary-poet-...-copy-fix-plan.json
data\reports\youtube-legendary-poet-...-copy-fix-report.md
```

План содержит полные `before_description`, `after_description`, точный `video_id`, исходную `revision` и список применённых детерминированных исправлений.
