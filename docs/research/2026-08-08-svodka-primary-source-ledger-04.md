## Самые сильные кандидаты для следующего пула

Для коротких постов: «Сатурн и вода», 16 закатов на МКС, голубой марсианский закат, 430 000 mph Parker Solar Probe, свет ниже 200 м, звук в воде, морской огурец, бивень-зуб нарвала, колибри задним ходом, абсолютный ноль.

Для `myth_fact`: океан «просто отражает небо», spring tide = весенний прилив, «тепловая молния», Yellowstone «просрочен», животные заранее знают землетрясение, полная Луна вызывает землетрясения, скорость света как обычная измеряемая константа.

## Editorial guards

1. Не превращать мысленный эксперимент «Сатурн плавал бы» в физически осуществимую сцену.
2. Для Европы писать `may / scientists think`, пока подлёдный океан не будет непосредственно подтверждён будущими измерениями.
3. Рекорды Parker Solar Probe перед будущим выпуском перепроверять по актуальной странице NASA.
4. Для приливов не обещать всем берегам строго два одинаковых high/low tide: локальная география меняет режим.
5. Для earthquake/tide темы сохранять нюанс: общей простой зависимости нет, но слабый tidal modulation для отдельных типов событий исследуется.
6. «Мухоловка считает» использовать как метафору сенсорной интеграции, не как утверждение о сознательном счёте.
7. Размер генома не трактовать как меру интеллектуальной или биологической сложности.
