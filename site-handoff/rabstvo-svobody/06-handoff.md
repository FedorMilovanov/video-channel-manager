## 2. Что сделано и в каком порядке

1. **Аудит исходника** (Telegram-версия, `main` `5ed369f`, 197 строк). 75 утверждений, вердикты
   `CONFIRMED / REVISE / EXPAND / UNSUPPORTED / DISPUTED`; два UNSUPPORTED сняты из статьи, три DISPUTED
   переписаны (детали — `01-audit.md`).
2. **Сверка Писания** по корпусу `bibleonline/rst` — все цитаты статьи, включая исправленные. В ходе
   сверки найдены и исправлены три ошибки, унаследованные от рабочей памяти, но не от исходника:
   * 1 Цар. 2:29 — в Синодальном «**предпочитаешь** Мне сыновей своих», а не «чтишь сыновей более Меня»;
   * Рим. 8:7 — порядок слов «**плотские помышления**», а не «помышления плотские»;
   * Евр. 12:10 — «по своему произволу **для немногих дней**», а не «на несколько дней».
3. **Сверка первоисточников** по оцифровкам (ECL) — Эдвардс, Лютер, Уэсли, Августин, Сперджен; локаторы в
   `02-sources.md`.
4. **Перестройка архитектуры:** семь значений свободы, разведение с «Свободой во Христе», раздел об
   ответственности (Эдвардс), спор Лютера и Эразма после анатомии воли, семейная часть с границами,
   финал по Августину.
5. **Два прохода:** содержательный (что утверждается и на каком основании) и литературный (объём цитат,
   отсутствие эмодзи, единый голос, переходы).
6. **Сжатие объёма:** 65,7 → 61,7 тыс. знаков за счёт служебных обзоров внутри текста; верхняя граница
   задания (60 тыс.) превышена примерно на 3%. Сокращать дальше можно только за счёт содержания; если
   нужен жёсткий лимит, первыми кандидатами идут раздел о ложной свободе и подглавка о бунте (без потери
   аргументации, за счёт примеров).

Скрипт сверки блочных цитат (проверяет, что каждая цитата с подписью `> (Книга гл:ст)` дословно
содержится в указанном диапазоне стихов):

```python
import re
from pathlib import Path
BOOKS={'Исх':'02-exodus','1 Цар':'09-1samuel','3 Цар':'11-1kings','Пс':'23-psalms','Прит':'24-proverbs',
'Иез':'34-ezekiel','Мал':'47-malachi','Мф':'52-matthew','Лк':'54-luke','Ин':'55-john','Деян':'56-acts',
'Рим':'64-romans','1 Кор':'65-1corinthians','Гал':'67-galatians','Еф':'68-ephesians','Флп':'69-philippians',
'Кол':'70-colossians','Евр':'77-hebrews','1 Ин':'60-1john','2 Пет':'59-2peter'}
def load(n):
    d={}
    for line in Path('/tmp/rst/parsed66/%s.dat'%n).read_text(encoding='utf-8').splitlines():
        m=re.match(r'^#(\d+):(\d+)#(.*)$',line)
        if m: d[(int(m.group(1)),int(m.group(2)))]=m.group(3)
    return d
def norm(t):
    t=t.replace('&mdash;','—').replace('<i>','').replace('</i>','').replace('&#769;','')
    t=re.sub(r'[^А-Яа-яЁёA-Za-z0-9 ]',' ',t).lower().replace('ё','е')
    return re.sub(r'\s+',' ',t).strip()
lines=open('04-site-article.md',encoding='utf-8').read().split('\n')
i=0; ok=fail=0
while i<len(lines):
    if lines[i].startswith('> ('):
        ref=lines[i][3:-1]; j=i-1; b=[]
        while j>=0 and lines[j].startswith('>'):
            b.insert(0,lines[j][1:].strip()); j-=1
        m=re.match(r'^(.+?)\s+(\d+):(\d+)(?:[–-](\d+))?$',ref); i+=1
        if not m or m.group(1).rstrip('.') not in BOOKS: continue
        d=load(BOOKS[m.group(1).rstrip('.')]); ch=int(m.group(2))
        v1=int(m.group(3)); v2=int(m.group(4) or m.group(3))
        N=norm(' '.join(d.get((ch,v),'') for v in range(v1,v2+1)))
        bad=[s for s in re.split(r'…|\.\.\.',' '.join(b)) if norm(s) and norm(s) not in N]
        ok,fail=(ok+1,fail) if not bad else (ok,fail+1)
        if bad: print('FAIL',ref,norm(bad[0])[:60])
    else: i+=1
print('ok',ok,'fail',fail)
```

**Результат на момент передачи:** `ok 22 fail 0` (плюс 19 цитат авторов, сверенных вручную по
оцифровкам, — локаторы в `02-sources.md`).

менять не нужно, кроме расширения.

## 5. Что не проверено и почему

| Пробел | Причина | Что сделано вместо |
|---|---|---|
| *De libero arbitrio* Эразма по критическому изданию | текста Эразма в доступных корпусах нет | определение цитируется по Лютеру (Sect. XLI), в статье и реестре это указано |
| постраничные ссылки на печатные издания Лютера и Эдвардса | в оцифровках нет пагинации | локаторы по разделам (Sect., Pt/§) |
| печатные лексиконы (BDB/HALOT) постранично | доступны только оцифрованные статьи | ссылка на статью BDB/Strong 3543 без выдуманных страниц |
| статистика о семьях и зависимости | заданием запрещена выдуманная статистика | статистика не приводится вовсе |
| техника телесных наказаний | Писание не даёт техники | вопрос оставлен открытым, названы запреты (ярость, унижение, требование греха) |

## 6. Спорные места, оставленные спорными

1. **כִּהָה (1 Цар. 3:13)** — hapax; «укорять» против «сдерживать». В статье сказано «не укорил, не
   остановил» с оговоркой о редкости слова; сильное физическое удержание не утверждается.
2. **Мера родительской власти над взрослым ребёнком** — принципы есть (почитание, отделение, забота),
   кодекса нет.
3. **Формы телесной дисциплины** — открытый вопрос, позиция: не ярость, не унижение, не принуждение к
   греху.
4. **Согласование всеобщего призыва и действенного привлечения** (Ин. 6:44 и Мф. 11:28) — обозначено, не
   решается догматически: конфессиональная нейтральность.
5. **Универсальность семейных закономерностей** — Илий и Адония даны как наблюдения, а не как закон.
