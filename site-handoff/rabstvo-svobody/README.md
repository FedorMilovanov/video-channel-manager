# Пакет передачи: «Рабство свободы» → gospod-bog.ru

## Что это

Иccледовательский и редакционный пакет для подготовки большой статьи сайта «Господь Бог — Сила Моя»
на основе уже изданной Telegram-статьи «Рабство свободы». Пакет **не является** публикацией: он
описывает аудит исходной рукописи, реестр проверенных источников, новую логическую архитектуру,
готовый черновик статьи для сайта и раскадровку иллюстраций.

## Как читать

1. `01-audit.md` — что в исходной статье подтверждено, что исправлено и почему.
2. `02-sources.md` — на чём стоит каждое утверждение и как это повторить.
3. `03-argument-map.md` — почему статья устроена именно так.
4. `04-site-article.md` — сам текст.
5. `05-visual-plan.md` — что рисовать и где ставить.

## Границы пакета

- Публикационный пайплайн Telegram (`scripts/`, `src/`, очереди, workflow) не затрагивался.
- Лимит 32 768 знаков относится только к Telegram-формату L2 и здесь не применялся.
- Изображения не генерировались; `05-visual-plan.md` — только задание художнику/генератору.
- Все библейские цитаты — Синодальный перевод; сверка выполнена по корпусу `bibleonline/rst`
  (`parsed66/*.dat`), сверка первоисточников — по ECL Obsidian Vault (см. `02-sources.md`).
- Статья не публиковалась: `draft: true`, изменения в репозиторий сайта не вносились.
