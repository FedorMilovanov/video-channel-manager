# Video Channel Manager — Terms of Use

**Effective:** 13 November 2026  
**Maintainer:** [Fedor Milovanov](https://github.com/FedorMilovanov)

Video Channel Manager is a privately operated, locally installed video-channel management application, not an official Google or YouTube product. Access is for the legitimate channel owner and other persons explicitly authorized by that owner.

### Authorized operation

An operator may connect and manage only channels for which the operator has proper authorization. Each action must identify the correct project, channel, and video or other resource. Content changes, publishing and deletion require the owner's explicit approval. No use of an account alias substitutes for identifying the correct project.

### YouTube API and service terms

The application uses YouTube API Services. **By using the YouTube-connected functionality, you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms).** The application must also comply with the [YouTube API Services Terms](https://developers.google.com/youtube/terms/api-services-terms-of-service) and [Developer Policies](https://developers.google.com/youtube/terms/developer-policies).

### Rights and privacy

The operator must possess the rights and permissions necessary for material published to connected channels. An API response does not grant permission to republish third-party audiovisual works. See the [Video Channel Manager Privacy Policy](PRIVACY.md) for information about data processing, Google authorization, revocation and deletion. Users may revoke the app's access via [Google Account permissions](https://security.google.com/settings/security/permissions).

### Contact

For a question or a non-sensitive request, contact the [repository maintainer](https://github.com/FedorMilovanov). Do not publish personal data or credentials in a GitHub issue. Request a private contact channel first.
