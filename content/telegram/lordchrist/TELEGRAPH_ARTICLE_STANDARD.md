# Стандарт двухслойных Telegraph-выпусков @lordchrist (lane L3)

Утверждено оператором 2026-10-24 по итогам пробного выпуска
`lordchrist-telegraph-charnock-01b`. Канонический источник правил для серии
«Чарнок» в формате: компактный пост в ленте канала + полный лонгрид Telegra.ph.

## 1. Два слоя

1. **Пост в ленте `@lordchrist`** (до 4 096 видимых знаков HTML): заголовок,
   подводка, одна открытая цитата, раскрывающийся конспект
   `<blockquote expandable>`, карточка Instant View с обложкой 16:9 и кнопкой
   «⚡ ПОСМОТРЕТЬ» (`link_preview_options`, `prefer_large_media=true`).
   Обычное сообщение канала: доступны репост в Stories, реакции, пересылка.
2. **Лонгрид Telegra.ph**: полный текст статьи, обложка 16:9 первой фигурой,
   заголовки `h3/h4`, цитаты, подвал источника.

## 2. Пост канала: раскрывающийся конспект

- Между пунктами конспекта — **пустая строка** (воздух); сплошная стена текста
  запрещена.
- Каждый пункт начинается с **жирного ввода** («Во-первых», «Единогласие
  поверх вражды.» и т. п.).
- Открытая цитата поста — блок `<blockquote>`, подпись — сразу под ним строкой
  `— Автор, «Труд»`, без вертикальной черты у подписи.

## 3. Цитаты в Telegra.ph

- Подпись цитаты стоит **вплотную под цитатой** отдельным абзацем-курсивом
  через длинное тире; вертикальная черта — только у самой цитаты, не у подписи.
- Цитаты Чарнока подписываются компактно:
  `— Стивен Чарнок, «О бытии Бога» (беседа I)` — слово «беседа» с маленькой
  буквы; длинные уточнения про довод/раздел в подпись не пишутся (для этого
  есть заголовки разделов). Цитаты Писания — только ссылка (`— Мал. 1:11`),
  без всяких тегов.
- **Запрет «мелкоцитатосыпа»**: норма цитаты — 400–1 200 знаков (потолок
  4 000). Идущие подряд цитаты без авторского текста между ними **склеиваются
  в одну** большую цитату; куски разделяются троеточием **в конце предыдущего
  куска** («…»), а не отдельной строкой; подпись — один раз в конце блока.
  Мелкие цитаты (< 250 знаков) допустимы только как афоризм-удар; если их
  больше 55% — preflight предупреждает, статья к выпуску не готова.
- **Акцент внутри цитат**: в длинных цитатах жирным выделяется максимум одна
  смысловая кульминация; курсив — термины и названия. Текст цитаты при этом
  не изменяется ни на букву; дословность по-прежнему проверяется EN-якорями.

## 4. Воздух и заголовки

- Перед большим заголовком — отбивка (воздух).
- Если раздел заканчивается цитатой с подписью, второй воздух перед следующим
  заголовком **не добавляется** (у цитатного блока свой отступ) — двойных
  провалов быть не должно.

## 5. Подвал источника

Последний абзац статьи начинается со знака копирайта:
`© Цитаты Чарнока — из книги «Беседы о существовании и атрибутах Бога» …`
(издание, оцифровка, ссылка на источник). Значки-эмодзи в серии запрещены;
знак `©` — не эмодзи, а типографский символ, и он обязателен.

## 6. Провенанс и проверки (без изменений)

- Каждая цитата имеет EN-якорь в `sources` дословно по источнику
  (Gutenberg #53527), цитаты Писания — по Синодальному переводу (RST).
- Перед публикацией: `lordchrist_article_sources_check.py`,
  `lordchrist_scripture_check.py --strict`, `lordchrist_article_preflight.py`
  — все с нулём расхождений, плюс два прогона вычитки (§11 L2-стандарта).
- «перевод мой» под цитатами не пишется; Лопухин не используется; эмодзи нет.

## 7. Публикация

- Паблишер: `video_channel_manager.lordchrist_telegraph_publisher`
  (команды `preview`, `publish-telegraph-only`, `publish`, `due`).
- Расписание: вт/пт 12:00 МСК (`due` + крон воркфлоу), дедуп по ledger на
  state-ветке; канарейка 01b — только вручную.
- Опубликованную страницу Telegra.ph отредактировать нельзя (одноразовый
  аккаунт, токен не сохраняется) — правки формата применяются к следующим
  выпускам, а не задним числом.

## 8. Специальные выпуски вне цикла (history)

- Отдельные статьи вне серии бесед получают `publication_id` вида
  `lordchrist-telegraph-charnock-history-NN` и файлы
  `lordchrist-telegraph-charnock-history-NN.{md,json}` (+ `*.quotes.json` —
  спецификация сборщика). Пример: воскресный
  `lordchrist-telegraph-charnock-history-01` (2026-10-25).
- В очереди такой выпуск — последним `ordinal`, `scheduled_on_moscow: null`,
  `is_canary: false`. Дата не назначается: `due` его не подхватит никогда
  (это закреплено тестом `test_history_special_is_manual_only`), расписание
  цикла не двигается; публикация — только ручным запуском (см. §10).
- К специальным выпускам применимы все правила §§2–6 без исключений.

## 9. Обложки

- Обложка делается **тремя баттлами** (`generate_image(offer_options=True)`,
  разные концепции, параллельно), выбирает оператор; в очередь идёт только
  выбранный кадр, строго 16:9 full-bleed, файл
  `media/<publication_id>-cover.jpg`.
- Если выпуск о **исторической личности** — сначала находятся подлинные
  изображения человека (гравюры/портреты, Wikimedia Commons и т. п.), и
  баттлы строятся **от этих референсов** (`media/_ref-*`), а не от
  выдуманных концепций. Референсы и выбранный баттл-кадр (`media/_battle-*`)
  сохраняются в репозитории рядом с обложками.
- Художественные сцены допустимы как драматизация, но известные
  анахронизмы/выдумка честно оговариваются в подвале статьи. Повторы
  однотипных «тёмных каменных залов» и скучные пейзажи запрещены.

## 10. Ручная публикация: точный воркфлоу и ловушки формы

- Воркфлоу: **Lordchrist Telegraph publisher**, файл
  `.github/workflows/lordchrist-telegraph-poster.yml` (обратите внимание:
  отображаемое имя — `publisher`, имя файла — `poster`).
- Форма Run workflow содержит **опасные значения по умолчанию**: `action`
  по умолчанию `publish-telegraph-only` (нужен `publish`), `publication_id`
  по умолчанию `lordchrist-telegraph-charnock-01b` (нужен точный ID
  выпуска), `confirm` должен быть точно `PUBLISH:<publication_id>`.
- Повторный `publish` того же ID паблишер отклоняет по ledger
  (`telegram_message_id` на state-ветке) — двойной пост невозможен.

## 11. Верификация биографических текстов

- Для статей о Чарноке первичный свод — отдел «БИОГРАФИИ/Стивен Чарнок»
  репозитория `FedorMilovanov/Research`: транскрипции надгробной проповеди
  Джона Джонсона (1680, EEBO-TCP `A46911`), эпистола издателей Richard Adams
  и Edward Veal (1684, `A79420`), Anthony Wood, *Athenae Oxonienses* (1691),
  и реестр конфликтов дат. Вторичный свод — DNB (Blaikie); DNB местами
  ошибается (например, «один том» при жизни вместо проповеди в сборнике
  под инициалами «S. C.»).
- Пасквиль Паркера (заговор 1663, «умер в 1683») — класс D, опорой не
  служит. «Знаменитый портрет» у Джонсона — литературный характер,
  скомпилированный из отцов Церкви, а не описание внешности; визуальных
  портретов два (картина в Williams' Library и гравюра фолио-издания).
- Неверифицированные числа (например, «четырнадцать бесед») в текст не
  вносятся, пока счёт не подтверждён оглавлением издания.

## 12. Сборка статьи (воспроизводимость)

- JSON статьи **не пишется руками**: он собирается из Markdown скриптом
  `scripts/build_lordchrist_telegraph_article.py` по спецификации
  `*.quotes.json` (порядок цитат, дословные EN-фразы начала/конца, метаданные,
  источники эпиграфа и Писания) и нормализованному тексту Gutenberg #53527;
  скрипт заодно пишет `--block`-аргументы для
  `lordchrist_article_sources_check.py`. Порядок прогона: сборщик →
  sources_check → scripture_check --strict → preflight → preview.
- Изменение любого файла в `scripts/wave-executors.json` (включая этот
  сборщик и VK-сплиттер) требует пересчёта его `sha256` в том же реестре.

## 13. Соседние лейны: очередь — общий ресурс

- `article-queue.json` читают не только Telegraph-паблишер:
  `scripts/build_lord_god_charnock_vk_posts.py` строит из неё VK-посты.
  Добавляя/переименовывая выпуск, проверьте VK-сплиттер и тесты со счётом
  статей. Путь обложки сплиттер берёт из очереди, а не вычисляет из
  `publication_id`; нецикловые (history) выпуски подписываются в VK как
  «Биографический очерк», а не «О бытии Бога».
