# Instagram launch sequence — August 2026

Status: provider-inert candidate sequencing  
Owner issue: #495

This file orders the existing source-bound candidates. It is not a publication schedule
and does not authorize provider writes. Timing/frequency is deliberately not encoded as
an algorithmic rule: the first live cadence should be a measured editorial experiment.

## Launch objective

A new visitor should understand each project after viewing only the first few pieces.
The launch therefore optimizes for **identity clarity + source trust + format diversity**
before optimizing for raw volume.

Do not make the first nine tiles visually uniform merely to manufacture a grid. Reels
are the primary discovery lane; carousels establish depth and save/share value.

## Legendary Poet creative rules for first live Reels

- Open with the poet + work identity visually or audibly; do not hide the subject behind
  a generic teaser.
- Use the most immediately intelligible musical movement, not automatically the first
  seconds of the full track.
- A clip boundary is an editorial choice and must be reviewed against the poem: do not
  cut a sentence/line so the fragment implies the opposite of the source.
- Build from the retained project master, never from a downloaded YouTube/VK/TikTok
  copy.
- On-screen historical likeness/visualization is presentation, not evidence. Do not add
  invented “quotes” to cinematic frames.
- For realistic-sounding generated audio, carry the recorded AI-audio disclosure state
  through to the future publish plan.
- Keep project branding present but subordinate to poet/work recognition.

## Lord God creative rules for first live pieces

- Hook with the actual biblical passage/question; never with spiritual threat or mystery
  bait.
- Use `текст говорит`, `вероятно`, `грамматика позволяет`, `мы считаем`, `текст не
  сообщает` according to the bound source's actual confidence level.
- Never use `напиши «Аминь»`, `лайк если веришь`, promised blessing for engagement, or
  fear-based share prompts.
- Scripture displayed verbatim requires an exact edition/source binding before final
  asset approval.
- For disputed supernatural material, an atmospheric visual may support attention but
  may not visually assert a reconstruction as if it were direct biblical description.
- Mix Bible study, church health and history so the account is not trained into a single
  sensational “hard texts” niche.

## Packaging template — Reel

Each future Reel package should contain at minimum:

```text
candidate_id
project_key
source IDs + frozen source revision
exact media input identity / SHA-256
selected clip start/end or derived vertical master identity
cover text
on-screen text / subtitle transcript
caption topic line
caption body
provenance / AI disclosure state when applicable
one CTA at most
hashtags / classification terms
recommendation-risk review state
exact Instagram account ID (future provider scope only)
```

The clip itself and the caption must tell the same story. A high-retention edit that
changes the source meaning fails editorial review.

## Packaging template — carousel

Every slide must have a purpose:

1. exact question / distinction;
2. first source-backed point;
3. second source-backed point;
4. boundary / caveat / contrast where needed;
5. concise conclusion;
6. optional source/continuation CTA.

The number of slides is determined by the argument, not by a fixed “optimal” count.
Delete a slide when it only repeats the caption.

## Learning plan after live rollout

Do not change strategy from one viral or weak post. Retain an exact creative/version ID
and compare repeated samples by content family.

### Poet comparisons

Compare separately:

- music excerpt Reels;
- exact-text + music Reels;
- editorial/provenance carousels.

Questions:

- Which poet/work families earn non-follower discovery?
- Which excerpts create shares/saves rather than passive plays only?
- Does putting author/work identity immediately on screen improve qualified viewing?
- Do provenance pieces improve profile exploration without displacing music discovery?

### Lord God comparisons

Compare separately:

- accessible Bible-concept Reels;
- difficult-text exegesis Reels;
- source-map/exegesis carousels;
- church-health material;
- church-history material.

Questions:

- Which subjects produce saves/shares rather than controversy-only comments?
- Do technical textual posts lead viewers into related material or merely create isolated
  spikes?
- Are hard-text topics overconcentrating the audience compared with broader Scripture,
  pastoral and history content?

## Stop / adjust signals

Treat these as editorial diagnostic signals, not automatic penalties:

- repeated low qualified consumption despite strong source material → inspect opening,
  edit, subtitles and cover before changing the subject itself;
- high views with low saves/shares/profile continuation → inspect whether the hook is
  attracting an audience that does not match the project;
- comments dominated by a misunderstanding the source already resolves → clarify the
  visual/caption framing;
- recommendation eligibility issue → stop rollout expansion and inspect Account Status /
  exact flagged content before further experiments;
- a format requiring unsupported claims or sensationalism to perform → abandon that
  format rather than weaken the source boundary.

## Deliberately not fixed yet

The repository does **not** yet declare:

- a universal posts-per-day rule;
- a universal best posting hour;
- a magic hashtag count;
- an ideal Reel duration independent of the source;
- a promise that 9:16, captions, a specific hook length or any other tactic guarantees
  distribution.

Those values become experiments only after exact live analytics exist for these two
specific accounts.
