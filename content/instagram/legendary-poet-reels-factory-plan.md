# The Legendary Poet — Reels factory plan

Status: **provider-inert / production planning**  
Built: 2026-08-20  
Owner issue: #495

This plan expands the Instagram program from isolated posts into a repeatable Reel factory built from exact existing project sources. It defines **59 distinct Reel jobs** from the already reviewed poetry/video/site corpus. It does **not** claim that 59 finished media files already exist.

A slot becomes executable only after its exact clean master, source span/timing, text edition where applicable, output geometry and SHA-256 are frozen.

## Non-negotiable production model

One long-form work may produce several Reels only when the Reels answer **different editorial questions**. We do not manufacture volume by chopping one performance into arbitrary adjacent fragments.

Valid Reel jobs include:

1. performance/music hook;
2. formal device in the poem;
3. composition/publication/manuscript history;
4. source-vs-myth correction;
5. image/motif or semantic contrast;
6. edition/variant evidence;
7. modern musical-interpretation provenance;
8. one focused interpretive question.

Invalid volume:

- five almost identical excerpts from one song;
- arbitrary `00:15–00:35` cuts before listening to/binding the exact master;
- copied YouTube description as Instagram caption;
- downloaded YouTube/VK encoding presented as a clean master;
- historical poet visually presented as if literally singing generated audio;
- invented quotation or punctuation from memory.

# What happens to the other 96 mapped videos

They are not discarded. They enter the mandatory intake from `legendary-poet-channel-video-intake.md`.

After fresh read-only YouTube scan, each gets one of four routes:

### Route S — native Short / vertical source

If exact current/provider evidence and a clean project-owned vertical master exist, produce an Instagram-native remaster. Keep the source content, but re-render cover/caption/safe zones for Instagram.

### Route L — long-form source

Score for 0–5 possible independent Reel jobs:

- performance hook;
- textual/formal device;
- manuscript/publication fact;
- source-vs-myth;
- visual/semantic motif.

Do not automatically create five. Zero is a valid score for weak/duplicate material.

### Route R — editorial rebuild

When the exact video identity is useful but the clean video master is absent, rebuild from project-owned audio, stills, source documents and new project-owned graphics. The old platform encoding is evidence, not a master.

### Route H — hold

Use for modern songs/adaptations, unresolved translations, uncertain image/music rights, misleading historical reconstructions or source-poor uploads.

# Reel scoring rubric

Every candidate gets 0–2 on each dimension:

1. **Hook clarity** — understandable on first frame without prior context.
2. **Source strength** — exact primary/academic source versus unsupported lore.
3. **Visual strength** — can work vertically without generic AI wallpaper.
4. **Audio strength** — exact clean master / intelligible self-contained moment.
5. **Distinctness** — adds a new editorial job rather than duplicating another Reel.
6. **Rights clarity** — public-domain/source-owned versus unresolved modern work.
7. **Bridge value** — naturally points to full track, article, playlist or site without CTA clutter.

Score bands:

- `12–14` → priority Reel;
- `9–11` → produce after first wave;
- `6–8` → rebuild/research;
- `0–5` → hold/archive.

Rights/source hard gates override the numerical score.

# Clean-master freeze contract

Before a Reel moves from concept to executable media:

```text
reel_id
project_key
youtube_source_id (if any)
site_source_path (if any)
clean_master_path
clean_master_sha256
width
height
duration_ms
selected_start_ms
selected_end_ms
selected_span_sha256 or deterministic edit manifest
canonical_text_source
canonical_text_span
caption_version
cover_version
ai_audio_disclosure
rights_status
```

No timestamp placeholders such as `best 20 sec`, `chorus`, `strong moment` survive into an executable plan.
